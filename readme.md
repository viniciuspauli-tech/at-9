RF1 — Cadastrar Dono: O sistema deve permitir cadastrar donos informando nome e e-mail.

RF2 — Cadastrar Animal: O sistema deve permitir que um dono cadastre um animal informando nome, raça, descrição, idade e porte.

RF3 — Listar Animais: O sistema deve apresentar todos os animais cadastrados, informando também o dono responsável pelo cadastro.

RF4 — Editar Animal: O sistema deve permitir alterar as informações de um animal já cadastrado.

RF5 — Excluir Animal: O sistema deve permitir excluir um animal já cadastrado.

RF6 — Listar Animais por Dono: O sistema deve permitir visualizar os animais cadastrados por um determinado dono.

RNF1 — Validação dos Campos: O sistema não deve permitir o cadastro de donos ou animais com campos obrigatórios vazios.

RNF2 — Segurança dos Dados: As operações que recebem informações fornecidas pelo usuário deverão utilizar Prepared Statements.
